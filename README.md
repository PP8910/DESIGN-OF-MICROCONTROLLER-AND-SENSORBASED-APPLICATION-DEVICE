# DESIGN-OF-MICROCONTROLLER-AND-SENSORBASED-APPLICATION-DEVICE : APARTMENT PARKING LOT
Dự án xây dựng mô hình bãi đỗ xe thông minh sử dụng vi điều khiển PIC16F877A, cảm biến hồng ngoại, servo và mô-đun RFID RDM6300. Hệ thống có khả năng nhận diện thẻ, điều khiển barrier, hiển thị LCD và giao tiếp máy tính qua UART.
